## ProviderView

Provides the handleAuth function that is executed on click on the button to
connect to the provider selected (Box, DropBox...)

It has in parameters authFormData

The ProviderView type is used in AuthView qnd it’s the AuthView used in the
ProviderView.

The ProviderView is used in the plugins in the install function where we pass in
parameters the provider.

The provider is created in the plugin also with the options.
